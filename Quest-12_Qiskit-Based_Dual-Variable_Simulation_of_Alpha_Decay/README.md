## 📜 Qiskit-Based Dual-Variable Simulation of Alpha Decay

### 🎯 Main Quest

Your primary mission is to **demonstrate the Quantum Tunneling workflow** by modeling, simulating, and verifying alpha decay predictions using Qiskit.

The goal: validate the relationship between:

- Barrier height: V₀  
- Particle kinetic energy: CT  
- Tunneling probability: P_tunnel

---

### ⭐ Side Quests (Steps to Success)

To complete your journey, tackle the following tasks:

#### 🧠 Side Quest 1: Hamiltonian to Pauli Mapping Mastery

- **Objective**: Finalize the **Physical Modeling** stage by:
  - Defining the alpha decay potential and kinetic energy
  - Translating the continuous Hamiltonian H into a **Pauli operator list** for a 4-qubit system

#### ⚙️ Side Quest 2: State Preparation Circuit Forge

- **Objective**: Build the **Initial Wavepacket Circuit** that encodes a 16-dimensional Gaussian wavepacket state onto 4 qubits

#### 🧪 Side Quest 3: Dual-Variable Simulation Run

- **Objective**: Execute two key experiments:
  1. Fix CT, vary V₀  
  2. Fix V₀, vary CT  
  - Pass numerical coefficients to the time-evolution circuit U(t)  
  - Run batch simulations using the Qiskit Sampler

Complete these quests to unlock new skills, gain experience, and progress toward your ultimate goal.
